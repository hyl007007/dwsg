## 本轮确认并修复的问题

| 范围 | 可复现问题 | 处理 |
| --- | --- | --- |
| 客户端连接 | 主动断开后，旧登录响应仍能重新恢复连接 | 为连接请求加入代次校验，取消过期请求及其回写 |
| 客户端登录 | 并发登录已被拒绝，却先覆盖了正在使用的凭据 | 在替换凭据之前判断是否正在连接 |
| 客户端断开 | 断开后仍保留角色、凭据和待重试命令 | 清理连接状态，结束排队回调；未知是否已提交的操作不声称已回滚 |
| 账号切换 | 新账号连接失败后仍保留旧账号连接与快照 | 显式连接前清除旧连接/角色视图，保留同请求 ID 的正常断线重试策略 |
| 服务端快照 | 较慢的旧轮询在相同世界版本下返回时，会覆盖较新的时间型投影；复用新快照时却返回旧事件水位 | 联动维护世界版本、快照时间和事件水位；投影期间新产生的事件仍留待后续响应 |
| 安卓安装工具 | Activity Manager 报错或超时但进程退出码为 0，工具误报启动成功 | `--launch` 同时要求 `Status: ok` 且无错误输出 |
| RK 发布工具 | 重复使用发布目录时，已从源码移除的 PHP 或旧 DLL 留在新包中 | 在同一输出目录记录生成文件清单，仅清理本工具上次生成的文件；失败构建也保留归属信息以便重试 |
